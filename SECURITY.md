# Security and privacy

This repository is a local prompt pack. It does not accept, upload, process, or
store bug bounty reports.

Do not send maintainers:

- unpublished vulnerability reports;
- private program briefs or NDA material;
- passwords, cookies, tokens, OTPs, recovery codes, or private keys;
- customer, employee, or other real-user data;
- screenshots, HAR files, or PoCs from an active disclosure.

Run reviews locally with a model or agent approved for the program material. A
private program report must not be uploaded to an unapproved hosted service.

If you find a security problem in this prompt pack itself, use the repository's
private security-advisory feature. Describe the prompt-pack issue with synthetic
examples only. Do not include details from an active bounty report.
