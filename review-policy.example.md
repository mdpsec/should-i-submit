# Optional hunter submission policy

This file is optional. Rename it to `review-policy.md` inside a report package
only when you want the reviewer to apply personal submission preferences in
addition to the supplied program rules.

Replace these examples with your choices:

- Minimum severity: Program rules only
- Submit technically valid Low findings: Yes
- Submit technically valid Informational findings: No
- Minimum SSRF severity: Program rules only
- Pure denial of service: Never submit
- Read-only public or low-sensitivity data: Require concrete material impact
- Duplicate-risk tolerance: Do not reject without supplied comparison evidence

Do not put credentials, target data, or vulnerability evidence in this file.
