# Safe example

`example-report/` shows the smallest valid report layout. It uses only synthetic
localhost data and is not a real vulnerability report.

`example-result.md` shows the short console decision and the kind of detail saved
to the local audit file. The real console prints the saved audit path instead of
printing the full technical review inline.

The localhost service used for maintainer QA is not included or required for
normal use. Point the reviewer at your own finished report directory instead.
